# Config VPN

Краткое описание: WireGuard и AmneziaWG: VPN-профили, правила для приложений и доменов.

Config VPN — клиент для подключения к выбранному VPN-серверу по протоколам WireGuard и AmneziaWG.

Возможности:
- Встроенный профиль и пять пользовательских слотов.
- Импорт конфигурации из файла, текста или QR-кода.
- Подключение и отключение VPN, отображение состояния и объёма трафика.
- App VPN: выбор приложений для VPN или обхода VPN, автоматическое подключение.
- Domain VPN: экспериментальное автоматическое включение по сохранённым доменам.
- Экспорт и импорт резервных копий, автоподключение и виджет.
- Настройка собственного сервера по SSH.

Приложение использует Android VpnService для создания зашифрованного туннеля от устройства до VPN-сервера. Для работы необходим доступный сервер с действительной конфигурацией. Доступность и скорость зависят от сервера и сети.

App VPN запрашивает доступ к статистике использования для определения активного приложения. Domain VPN по отдельному согласию использует AccessibilityService для чтения адресов, ссылок и текста в браузерах и Telegram и определения активного приложения. Эти данные обрабатываются локально для ваших правил автоматического подключения. Приложение не является инструментом специальных возможностей для людей с инвалидностью. Дополнительные разрешения можно отключить в настройках Android.

Выбирайте VPN-сервер, оператору которого доверяете. Резервные копии содержат секретные ключи: передавайте их только доверенному получателю.
