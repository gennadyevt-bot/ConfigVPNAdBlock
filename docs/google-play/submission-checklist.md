# Подготовка отправки Config VPN

Не отправлять без проверки владельцем. STOP VPN и Stop-vpn1 не относятся к этому проекту.

## Декларации
- VpnService: основная функция — VPN. WireGuard/AmneziaWG шифрует туннель до сервера. Требуются декларация Play Console и видео фактического подключения с экраном согласия.
- Accessibility: не accessibility tool; дополнительная автоматизация по пользовательским доменным правилам. Показать диалог раскрытия данных, отказ, согласие, включение сервиса и результат. Окончательное решение принимает Google.
- Foreground service specialUse: поддержание VPN и выбранной пользователем автоматизации App VPN. Показать постоянное уведомление и отключение.
- QUERY_ALL_PACKAGES убрано: App VPN использует уже объявленный MAIN/LAUNCHER query.
- Data safety: нельзя автоматически ответить «данные не собираются», пока владелец не подтвердит обработку/хранение данных встроенным сервером, GitHub и практику третьих лиц.
- Заполнить анкету возраста, целевую аудиторию, страны, наличие рекламы и доступ для проверки по фактическим сведениям владельца.
- При применимости требований нового личного аккаунта пройти закрытый тест по условиям Play Console. Проверить App signing, занятость com.config.app и предыдущие versionCode.

## Материалы
- Название, описание и заметки версии: соседние файлы.
- Email подтверждён: configvpn.app@gmail.com. Нужны имя разработчика и опубликованная политика конфиденциальности.
- Владелец подтвердил: первая публикация, телефона для тестирования нет. Нужны настоящие скриншоты собранной версии и видеозаписи для деклараций; не подменять их макетами.
- Иконка 512×512 и feature graphic 1024×500; проверить качество исходной иконки перед загрузкой.

## Подпись
Последний опубликованный GitHub APK v5.0.7 имеет Android Debug DN, SHA-256 2d16864d1463722e8a6375c5a839b9bdfbec1ab3f8558da5407d3ac6a7fd2a62.
Новая постоянная подпись отличается: обновление поверх тестового APK без миграции не гарантируется. До удаления старого приложения экспортировать профили и безопасно сохранить их.
Для первой публикации выбрать стратегию Play App Signing. Если Google создаёт app-signing key, сертификат APK из Play отличается от upload key локального APK. Если пакет уже зарегистрирован, сначала сравнить сертификат upload key в Console.
Новый PKCS12 и защищённый DPAPI пароль находятся вне Git в ConfigVPN-signing. DPAPI привязан к текущему Windows-пользователю/ПК: переносимый пароль сохранён в ПАРОЛЬ-КЛЮЧА.txt; ключ и этот пароль по просьбе владельца загружены в его отдельную папку Яндекс Диска. Не публиковать их в Git, переписке или артефактах CI.

## Найденные препятствия публичному релизу
- В исходном репозитории уже присутствуют приватные VPN-ключи в assets/server1.conf и configs/Config_PC_WG_51820.conf. Значения не воспроизводить. Встроенный профиль сохранён ради совместимости; перед публичным релизом владельцу нужно подтвердить модель выдачи доступа и заменить скомпрометированные учётные данные на сервере. Удаление файла из HEAD не удаляет историю Git; секрет внутри APK также извлекается.
- OwnServerSetup теперь запрашивает подтверждение отпечатка SSH и сохраняет known_hosts; дополнительно проверяет формат адреса и порта. Серверный установочный скрипт не проверялся на реальном сервере. Никакие удалённые серверы в рамках подготовки не перенастраивались.
- Нужен реальный тест handshake, передачи трафика, DNS/IPv6, App VPN, Domain VPN, перезапуска и импорт/экспорт на поддерживаемых Android, включая API 36 и 16 KB.
