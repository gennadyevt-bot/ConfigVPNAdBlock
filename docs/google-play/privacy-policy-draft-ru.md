# Политика конфиденциальности Config VPN — проект для проверки владельцем

Контакт для вопросов и запросов: configvpn.app@gmail.com.

Дата: 13 сентября 2026 года. Идентификатор приложения: com.config.app.

**Перед публикацией заполнить:** юридическое/публичное имя ответственного разработчика,  постоянный публичный HTTPS-адрес этой политики. Отдельно подтвердить практику оператора встроенного VPN-сервера. Этот проект нельзя выдавать за подтверждённую политику сервера.

Config VPN хранит на устройстве VPN-конфигурации, секретные ключи, выбранные приложения, доменные правила и настройки подключения. Приложение создаёт зашифрованный WireGuard/AmneziaWG-туннель. VPN-сервер получает исходный IP и передаваемый через него трафик; оператор может видеть адреса назначений и содержимое незашифрованных соединений. Шифрование VPN заканчивается на сервере; HTTPS обеспечивает отдельную защиту до сайта.

App VPN использует перечень запускаемых приложений и статистику их использования для автоматического подключения. Domain VPN использует Accessibility для чтения ссылок, адресов и текста браузеров/Telegram и имени активного приложения, чтобы находить совпадения с локальными правилами. Обработка выполняется на устройстве; в проверенном клиентском коде нет отправки этих данных разработчику или рекламной аналитике. Domain VPN является дополнительной функцией, а не средством помощи людям с инвалидностью.

По запросу пользователя обновление списка серверов обращается к GitHub. GitHub получает обычные сетевые сведения запроса, включая IP. При настройке собственного сервера приложение передаёт введённые SSH-учётные данные выбранному серверу по SSH. При QR-сканировании используется камера; при импорте пользователь сам выбирает файл.

Автоматическое резервное копирование Android отключено. Ручной экспорт содержит конфигурации и секретные ключи и передаётся только выбранному пользователем получателю. Локальный журнал диагностики может содержать время, ошибки и результаты сетевых проверок. Полные VPN-ключи и URL из Accessibility не записываются новой версией.

Разрешения Usage Access, Accessibility, уведомлений и VPN можно отозвать через настройки Android. Данные можно удалить очисткой данных приложения или его удалением; отдельно удалите экспортированные копии. Удаление локальных данных не удаляет журналы стороннего VPN-сервера: обратитесь к его оператору.

В проверенном клиентском коде не обнаружены реклама, регистрация аккаунта или SDK рекламной аналитики. Это не подтверждает отсутствие сбора данных сервером.
